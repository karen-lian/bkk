# 城市線稿

Hero 底下那張橫幅是**手寫 SVG 線稿，不是圖片**。這是整份手冊最有個性的部分，
也是換城市時唯一需要真正創作的東西。

## 技術框架（不要改）

```html
<div class="wrap art" aria-hidden="true">
<svg viewBox="0 0 1200 440" role="img">
  <defs><!-- pattern 定義 --></defs>
  <g><!-- 層 1 --></g>
  <g><!-- 層 2 --></g>
  ...
</svg>
</div>
```

- `viewBox="0 0 1200 440"` 固定，寬幅比例。地面線放在 y≈396–440 之間。
- **每個 `<g>` 是一個進場動畫層**，CSS 已經幫 `:nth-child(1)~(5)` 排好延遲（.05s 遞增）。
  所以請控制在 **4–5 層**，多了不會有動畫。
- 線條 class：`.st`（1px，主要輪廓）／`.thin`（0.6px，細節與紋理）／`.bold`（1.6px，強調）
- `stroke` 一律 `var(--ink)`（由 `.st` 統一設定），`fill` 只用 `var(--paper)` 做挖空（`.cut`）
- 顏色永遠不要寫死，才能跟著主題切換

## 分層順序

由遠到近，這個順序也決定了動畫進場的先後：

1. **天空／背景** — 電纜、雲、遠山、橋的上部結構
2. **地標** — 那座城市一眼認得出來的東西（塔、廟、教堂、橋）
3. **中景建築** — 街屋、公寓、店面，用 `<pattern>` 填窗格
4. **街面** — 地面線、人（火柴人）、車輛、攤販、植栽

## 用 `<pattern>` 做密度

不要一格一格畫窗戶。定義 pattern 再用 `<rect fill="url(#winA)">` 填滿，
這是讓畫面有密度又不會讓檔案爆掉的關鍵：

```html
<pattern id="winA" width="17" height="21" patternUnits="userSpaceOnUse">
  <rect x="4.5" y="5.5" width="8" height="10" fill="none" stroke="currentColor" stroke-width=".55"/>
</pattern>
<pattern id="hatch" width="7" height="7" patternUnits="userSpaceOnUse">
  <path d="M-1,8 L8,-1" fill="none" stroke="currentColor" stroke-width=".55"/>
</pattern>
```

`stroke="currentColor"` 很重要——pattern 內部無法直接吃 `.st`，靠 `.art svg{color:var(--ink)}`
繼承。

## 挑母題

選 **5–7 個母題**，要有這幾類各至少一個，然後左右錯落排開、高度要有變化：

| 類別 | 曼谷用了什麼 | 換城市時想什麼 |
|---|---|---|
| 一眼認得的地標 | 鄭王廟塔 | 這座城市明信片上的那個東西 |
| 在地建築語彙 | 店屋、鐵皮加蓋 | 街上真的長那樣的房子 |
| 現代天際線 | Mahanakhon 像素塔 | 有沒有一棟造型特殊的高樓 |
| 交通工具 | 嘟嘟車、機車 | 當地特有的載具 |
| 街頭生活 | 路邊攤、遮陽傘 | 那條街上會有的攤子或家具 |
| 環境紋理 | 頭頂電纜亂線 | 這城市抬頭會看到什麼 |
| 植物 | 盆栽 | 當地常見的樹或盆栽 |
| 人 | 火柴人 | 一定要有，給尺度感 |

**關鍵在「在地感」不在「知名度」**。頭頂那團亂七八糟的電纜比廟塔更像曼谷。
找那種「只有這裡才這樣」的細節。

## 幾個城市的母題建議

- **東京** — 鳥居、看板密集的雜居大樓、山手線高架、自販機、腳踏車、電線杆、櫻花或銀杏
- **京都** — 町家格子窗、五重塔、鴨川堤、人力車、竹、暖簾
- **首爾** — 韓屋屋簷曲線、公寓群棟編號、南山塔、路邊帳篷攤、招牌堆疊
- **里斯本** — 磁磚立面（用 pattern）、28 號電車、聖若熱城堡、曬衣繩、陡坡階梯
- **威尼斯** — 貢多拉、水岸柱、拱窗、晾衣繩、鐘樓
- **紐約** — 逃生梯、水塔、格狀窗、黃色計程車、消防栓、地鐵通風口蒸氣
- **香港** — 招牌懸挑、竹鷹架、叮叮車、唐樓騎樓、冷氣機外掛

## 檢查

- 三組配色 × 明暗 全部切一次，線稿都要看得見（不會太淡或糊掉）
- 手機寬度下不要糊成一團——`vector-effect:non-scaling-stroke` 已經處理了線寬，
  但**細節密度**要自己控制，太密的紋理在 390px 寬會變成灰塊
- `aria-hidden="true"` 保留，這是純裝飾，不需要被螢幕閱讀器讀出來
