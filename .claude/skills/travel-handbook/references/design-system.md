# 設計系統

## 核心約束：一個墨色 + 一張紙

整份網站只用**一個墨色（`--ink`）+ 一個紙色（`--paper`）**。所有層次靠線條粗細與網點密度
做出來，這是絹印海報的邏輯。**不要引入第三個顏色**——加了之後，「用深淺區分重要性」這套
規則就失效，整個資訊結構會散掉。

透明度階層由 `--ink-rgb` 產生：`--ink-85 / -60 / -38 / -18 / -08`。
新元素一律使用這些變數，不要寫死色碼，否則切換主題時會脫色。

## 挑城市配色

三組配色不是隨機三個顏色，是**這座城市的三種面貌**，每一組都要講得出出處。
曼谷的三組是計程車桃紅、廟宇金、湄南河靛藍——都是在那座城市真的會看到的顏色。

### 步驟

1. 想三個這座城市的視覺母題（交通工具／宗教建築／水域／土壤／招牌／季節植物）
2. 每個母題取一個代表色當 light 模式的 `--ink`
3. `--paper` 用同色系但極淡的紙色，**帶一點該色的溫度**，不要用純白
4. dark 模式：`--ink` 提亮到接近粉彩，`--paper` 壓到接近黑但**保留色相**，不要用純黑 `#000`
5. 跑檢查腳本

### 數值範圍

| | light | dark |
|---|---|---|
| `--ink` | 深、飽和，明度約 25–40% | 亮、明度約 60–75% |
| `--paper` | 明度 92–96%，帶微量墨色色相 | 明度 4–9%，帶微量墨色色相 |

### 檢查

```bash
python3 scripts/check_palette.py --file index.html
```

門檻與理由：

- **base（ink vs paper）≥ 4.5** 是硬底線，這是 WCAG AA 對一般字級的要求，正文不能低於它。
- **base ≥ 7** 才算舒服。這時 `--ink-60` 約 3.3 以上，備註文字還讀得動。

**要知道的取捨**：`--ink-60` 用在 `.cost-note`、`.stop .note`、`.eyebrow` 這些次要層級，
實測即使 base 到 9.6，ink-60 也只有 4.1，仍未跨過 WCAG AA 的 4.5。這是 60% 透明度這個
設計選擇的固有結果。所以**硬底線時間、金額、警告不要只放在次要層級**——要放進 `.alert`
或用 `<b>` 提到主層級。曼谷那份實測 base 5.4–9.6 在手機上使用沒問題，5.x 是「可用但要
知道取捨」，不是壞掉。

## 字型

三支，不要再加，也**不要因為換國家就換掉前兩支**——它們是這套手冊的識別：

- `Bai Jamjuree` — 拉丁字與數字
- `Noto Sans TC` — 中文
- `Noto Sans <Script>` — 當地文字，class `.loc`。只有這支隨目的地換
  （日本 `Noto Sans JP`、韓國 `Noto Sans KR`、印度 `Noto Sans Devanagari`…）。
  目的地用拉丁字母就整支從 Google Fonts 網址移除，並拿掉 `.loc` 的用法。

## 間距

三層標題各自「上方留白 = 下方留白」：

```css
--gap-major: clamp(40px,6vw,64px)   /* 區塊大標題 */
--gap-mid:   clamp(28px,4vw,44px)   /* 每日日期標題 */
--gap-sub:   clamp(22px,3vw,34px)   /* 次分類標題 */
```

## 圓點編碼：結構即資訊

行程是一條連續直線，每個時間點的圓點編碼「誰參加」。**這套編碼本身就是資訊**，
不是裝飾，不要為了好看去改：

| class | 外觀 | 意義 |
|---|---|---|
| `.stop.together` | 實心 | 兩人同行 |
| `.stop`（無修飾） | 空心 | 各自行動 |
| `.stop.pending` | 半實心 | 待定／待確認 |
| `.day-head::before` | 雙層同心圓 | 日期節點（刻意與「各自行動」的單層空心圈區隔） |

半實心必須**同時**配文字說明（例如「官方 8/16 才公告」）。只靠顏色或形狀傳達狀態，
對色覺障礙者與小螢幕使用者都不可靠。

## 動效與版面變異

在克制的單色系統上疊了一層編舞感動效，**不是取代單色約束，是在同一套系統裡拉高表現力**。

- **進場**：`.rv` 用 `translateY + scale` 的 settle 動畫；內部卡片／列表項目用 `nth-child`
  疊加 `transition-delay` 逐項掉落，第 5 項起延遲封頂（170ms），長清單不會拖太久。
- **互動微動效**：按鈕 hover/active 都有小幅 `transform`，不是只變顏色。
- **版面變異只用在裝飾性元素**：編號徽章旋轉出血、`.day-num` 奇偶交替微旋轉、
  `.duo` 卡片垂直錯位、`.cost-cols` 非對稱欄寬。
- **承載資訊的結構完全不動**：行程時間軸直線、`.places` 共用邊框網格。那些規律本身
  就是資訊（誰同行、分類），歪掉是犧牲可讀性換好看。
- **所有動效都要在 `prefers-reduced-motion` 裡歸零**，新增動效時記得一併補上。
